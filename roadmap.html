Project Management / Profiles Dashboard API

A 50-hour, step-by-step build plan using FastAPI + PostgreSQL + S3, following the Controller–Service–Repository (three-layer) architecture.

Approach & Architecture read first

We will build this incrementally, in vertical slices rather than laying out the whole folder tree up front. Each phase adds one working, tested capability end-to-end (route → service → repository → DB/S3), and every phase ends with a green test suite and a git commit. This mirrors how you'd actually work on a real team: small PRs, CI green on every merge, no big-bang integration at the end.

The core structural decision is the Controller–Service–Repository (CSR) pattern, a standard layered architecture that keeps concerns separated and testable:

Controller
FastAPI routers. Parses/validates HTTP input (Pydantic), calls a Service, returns a response. No SQL, no business rules here.
Service
Business logic & orchestration (e.g. "creating a project also grants owner access"). Talks only to Repositories and other Services, never to the DB session directly for queries.
Repository
Data access only. One repository per aggregate (User, Project, Document, Access). Wraps SQLAlchemy queries. Swappable/testable in isolation.

Below that sit Models (SQLAlchemy ORM entities) and Schemas (Pydantic request/response DTOs) — kept as separate modules so the DB shape and the API shape are free to diverge (e.g. never returning hashed_password).

Auth: stateless JWT (1h expiry) issued at POST /login, verified per-request via a FastAPI dependency (get_current_user) that decodes the token and loads the user through the UserRepository. Authorization (owner vs participant) is a second dependency layered on top, resolved through AccessRepository.

Storage: documents go to S3 (never through the app server's disk for long-term storage — stream to S3 directly). An S3 ObjectCreated event triggers a Lambda that (a) resizes images if applicable and (b) recalculates the project's total storage usage and enforces a quota.

Testing: pytest + pytest-asyncio + FastAPI's TestClient, a disposable SQLite (or Dockerized Postgres via testcontainers) per test session, and moto to mock S3/Lambda in unit tests — no real AWS calls in CI. Coverage tracked with pytest-cov. Tests are added with every phase, not bolted on at the end.

Tooling: ruff (lint+format, replaces flake8/isort/black), mypy (type checking), pre-commit (git hooks), pydantic-settings (typed .env loading), alembic (migrations), poetry (dependency + packaging), Docker/docker-compose (local Postgres + app), GitHub Actions (lint → test → build → push → deploy on merge to main).

Git strategy: one feature branch per phase (feat/phase-1-skeleton, etc.), small commits inside it, PR into main, CI must pass before merge. Commit messages follow Conventional Commits (feat:, fix:, test:, chore:, ci:).

from functools import lru_cache
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", env_file_encoding="utf-8")

    # App
    ENV: str = "local"
    SECRET_KEY: str
    JWT_ALGORITHM: str = "HS256"
    JWT_EXPIRE_MINUTES: int = 60

    # Database
    POSTGRES_USER: str
    POSTGRES_PASSWORD: str
    POSTGRES_DB: str
    POSTGRES_HOST: str = "db"
    POSTGRES_PORT: int = 5432

    @property
    def DATABASE_URL(self) -> str:
        return (
            f"postgresql+psycopg2://{self.POSTGRES_USER}:{self.POSTGRES_PASSWORD}"
            f"@{self.POSTGRES_HOST}:{self.POSTGRES_PORT}/{self.POSTGRES_DB}"
        )

    # AWS / S3
    AWS_ACCESS_KEY_ID: str = ""
    AWS_SECRET_ACCESS_KEY: str = ""
    AWS_REGION: str = "eu-central-1"
    S3_BUCKET_NAME: str = "projects-dashboard-docs"
    S3_ENDPOINT_URL: str | None = None  # set for local MinIO/moto testing

    # Limits
    MAX_PROJECT_STORAGE_MB: int = 500


@lru_cache
def get_settings() -> Settings:

2.4 Generic Repository base 1.5h

The Repository layer is deliberately generic where it can be, and specialized where the query is domain-specific (e.g. "projects a user has access to").

app/repositories/base.py
import uuid
from typing import Generic, TypeVar

from sqlalchemy.orm import Session

from app.db.base import Base

ModelType = TypeVar("ModelType", bound=Base)


class BaseRepository(Generic[ModelType]):
    """Generic CRUD operations, reused by every concrete repository."""

    def __init__(self, model: type[ModelType], db: Session) -> None:
        self.model = model
        self.db = db

    def get(self, id_: uuid.UUID) -> ModelType | None:
        return self.db.get(self.model, id_)

    def add(self, instance: ModelType) -> ModelType:
        self.db.add(instance)
        self.db.commit()
        self.db.refresh(instance)
        return instance

    def delete(self, instance: ModelType) -> None:
        self.db.delete(instance)
        self.db.commit()

class UserCreate(BaseModel):

3.2 Security core: hashing + JWT 1h

app/core/security.py
import uuid
from datetime import datetime, timedelta, timezone

from jose import JWTError, jwt
from passlib.context import CryptContext

from app.core.config import get_settings

settings = get_settings()
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")


def hash_password(plain: str) -> str:
    return pwd_context.hash(plain)


def verify_password(plain: str, hashed: str) -> bool:
    return pwd_context.verify(plain, hashed)


def create_access_token(user_id: uuid.UUID) -> str:
    expire = datetime.now(timezone.utc) + timedelta(minutes=settings.JWT_EXPIRE_MINUTES)
    payload = {"sub": str(user_id), "exp": expire}
    return jwt.encode(payload, settings.SECRET_KEY, algorithm=settings.JWT_ALGORITHM)


def decode_access_token(token: str) -> uuid.UUID | None:
    try:
        payload = jwt.decode(token, settings.SECRET_KEY, algorithms=[settings.JWT_ALGORITHM])
        return uuid.UUID(payload["sub"])
    except (JWTError, KeyError, ValueError):
        return None

app/services/auth_service.py
from sqlalchemy.orm import Session

from app.core.security import create_access_token, hash_password, verify_password
from app.exceptions import InvalidCredentialsError, UserAlreadyExistsError
from app.models.user import User
from app.repositories.user_repository import UserRepository
from app.schemas.user import UserCreate, UserLogin


class AuthService:
    def __init__(self, db: Session) -> None:
        self.users = UserRepository(db)

    def register(self, payload: UserCreate) -> User:
        if self.users.get_by_login(payload.login):
            raise UserAlreadyExistsError(f"login '{payload.login}' is already taken")
        user = User(login=payload.login, hashed_password=hash_password(payload.password))
        return self.users.add(user)

    def login(self, payload: UserLogin) -> str:
        user = self.users.get_by_login(payload.login)
        if not user or not verify_password(payload.password, user.hashed_password):
            raise InvalidCredentialsError("invalid login or password")
        return create_access_token(user.id)

Notice the service raises plain Python exceptions, not HTTP exceptions — it has no knowledge of FastAPI. The router translates domain errors to status codes. This keeps the service layer reusable (e.g. from a CLI or a background worker) and unit-testable without spinning up HTTP.

app/services/project_service.py
import uuid

from sqlalchemy.orm import Session

from app.exceptions import NotFoundError, PermissionDeniedError
from app.models.access import Role
from app.models.project import Project
from app.repositories.access_repository import AccessRepository
from app.repositories.project_repository import ProjectRepository
from app.schemas.project import ProjectCreate, ProjectUpdate


class ProjectService:
    def __init__(self, db: Session) -> None:
        self.db = db
        self.projects = ProjectRepository(db)
        self.access = AccessRepository(db)

    def create(self, owner_id: uuid.UUID, payload: ProjectCreate) -> Project:
        project = self.projects.add(Project(name=payload.name, description=payload.description))
        # business rule: creator automatically becomes owner
        self.access.grant(owner_id, project.id, Role.OWNER)
        return project

    def list_for_user(self, user_id: uuid.UUID) -> list[Project]:
        return self.projects.list_for_user(user_id)

    def get_if_authorized(self, user_id: uuid.UUID, project_id: uuid.UUID) -> Project:
        project = self.projects.get(project_id)
        if project is None:
            raise NotFoundError("project not found")
        if self.access.get_for_user_and_project(user_id, project_id) is None:
            raise PermissionDeniedError("no access to this project")
        return project

    def update(self, user_id: uuid.UUID, project_id: uuid.UUID, payload: ProjectUpdate) -> Project:
        project = self.get_if_authorized(user_id, project_id)  # any role may update, per spec
        if payload.name is not None:
            project.name = payload.name
        if payload.description is not None:
            project.description = payload.description
        self.db.commit()
        self.db.refresh(project)
        return project

    def delete(self, user_id: uuid.UUID, project_id: uuid.UUID) -> None:
        project = self.projects.get(project_id)
        if project is None:
            raise NotFoundError("project not found")
        access = self.access.get_for_user_and_project(user_id, project_id)
        if access is None or access.role != Role.OWNER:
            raise PermissionDeniedError("only the owner can delete this project")
        self.projects.delete(project)  # cascade removes access rows + documents rows (S3 cleanup in service below)
Note on document deletion
The DB cascade removes documents rows, but S3 objects are not deleted by a DB cascade. In Phase 5 we'll wire DocumentService.delete_all_for_project into this flow before the DB delete, so S3 objects are actually removed too.

import uuid

from fastapi import UploadFile
from sqlalchemy.orm import Session

from app.core.config import get_settings
from app.core.s3 import get_s3_client
from app.exceptions import AppError, NotFoundError
from app.models.document import Document
from app.repositories.document_repository import DocumentRepository

settings = get_settings()
ALLOWED_CONTENT_TYPES = {
    "application/pdf",
    "application/vnd.openxmlformats-officedocument.wordprocessingml.document",  # .docx
}


class StorageLimitExceededError(AppError):
    pass


class UnsupportedFileTypeError(AppError):
    pass


class DocumentService:
    def __init__(self, db: Session) -> None:
        self.db = db
        self.documents = DocumentRepository(db)
        self.s3 = get_s3_client()

    def upload(self, project_id: uuid.UUID, file: UploadFile) -> Document:
        if file.content_type not in ALLOWED_CONTENT_TYPES:
            raise UnsupportedFileTypeError(f"unsupported content type: {file.content_type}")

        body = file.file.read()
        size = len(body)

        current_total = self.documents.total_size_for_project(project_id)
        limit_bytes = settings.MAX_PROJECT_STORAGE_MB * 1024 * 1024
        if current_total + size > limit_bytes:
            raise StorageLimitExceededError("project storage limit exceeded")

        key = f"projects/{project_id}/{uuid.uuid4()}-{file.filename}"
        self.s3.put_object(
            Bucket=settings.S3_BUCKET_NAME, Key=key, Body=body, ContentType=file.content_type
        )
        doc = Document(
            project_id=project_id,
            filename=file.filename or "unnamed",
            content_type=file.content_type,
            s3_key=key,
            size_bytes=size,
        )
        return self.documents.add(doc)

    def get_download_stream(self, document_id: uuid.UUID) -> tuple[Document, bytes]:
        doc = self.documents.get(document_id)
        if doc is None:
            raise NotFoundError("document not found")
        obj = self.s3.get_object(Bucket=settings.S3_BUCKET_NAME, Key=doc.s3_key)
        return doc, obj["Body"].read()

    def delete(self, document_id: uuid.UUID) -> None:
        doc = self.documents.get(document_id)
        if doc is None:
            raise NotFoundError("document not found")
        self.s3.delete_object(Bucket=settings.S3_BUCKET_NAME, Key=doc.s3_key)
        self.documents.delete(doc)

    def delete_all_for_project(self, project_id: uuid.UUID) -> None:
        for doc in self.documents.list_for_project(project_id):
            self.s3.delete_object(Bucket=settings.S3_BUCKET_NAME, Key=doc.s3_key)
            self.documents.delete(doc)

        self.access.grant(invitee.id, project_id, Role.PARTICIPANT)

7.1 Image resize Lambda 1.5h

lambda/resize_handler.py
import io
import os

import boto3
from PIL import Image

s3 = boto3.client("s3")
MAX_DIMENSION = 1024


def handler(event, context):
    for record in event["Records"]:
        bucket = record["s3"]["bucket"]["name"]
        key = record["s3"]["object"]["key"]

        if not key.lower().endswith((".png", ".jpg", ".jpeg")):
            continue  # non-image documents skip resizing

        obj = s3.get_object(Bucket=bucket, Key=key)
        image = Image.open(io.BytesIO(obj["Body"].read()))
        image.thumbnail((MAX_DIMENSION, MAX_DIMENSION))

        buffer = io.BytesIO()
        image_format = image.format or "PNG"
        image.save(buffer, format=image_format)
        buffer.seek(0)

        resized_key = key.replace("projects/", "projects-resized/", 1)
        s3.put_object(Bucket=bucket, Key=resized_key, Body=buffer, ContentType=obj["ContentType"])

    return {"statusCode": 200}

7.2 Storage-size limit Lambda 1.5h

lambda/size_calculator.py
import os

import boto3
import psycopg2

s3 = boto3.client("s3")
MAX_PROJECT_STORAGE_MB = int(os.environ.get("MAX_PROJECT_STORAGE_MB", "500"))


def _project_id_from_key(key: str) -> str:
    # key format: projects//-
    return key.split("/")[1]


def handler(event, context):
    conn = psycopg2.connect(os.environ["DATABASE_URL"])
    try:
        for record in event["Records"]:
            bucket = record["s3"]["bucket"]["name"]
            key = record["s3"]["object"]["key"]
            project_id = _project_id_from_key(key)

            total_bytes = 0
            paginator = s3.get_paginator("list_objects_v2")
            for page in paginator.paginate(Bucket=bucket, Prefix=f"projects/{project_id}/"):
                for obj in page.get("Contents", []):
                    total_bytes += obj["Size"]

            with conn.cursor() as cur:
                cur.execute(
                    "UPDATE projects SET storage_bytes = %s WHERE id = %s",
                    (total_bytes, project_id),
                )
            conn.commit()

            if total_bytes > MAX_PROJECT_STORAGE_MB * 1024 * 1024:
                # flag project as over-quota; app layer blocks further uploads on next check
                with conn.cursor() as cur:
                    cur.execute(
                        "UPDATE projects SET over_quota = TRUE WHERE id = %s", (project_id,)
                    )
                conn.commit()
    finally:
        conn.close()

    return {"statusCode": 200}

Best Practices & Recommendations read throughout

Layering discipline
Never let a router import a Repository directly, and never let a Repository raise HTTPException. If you find yourself doing either, the boundary has leaked — pull the logic into the Service.
Schemas ≠ Models
Keep Pydantic schemas and SQLAlchemy models in separate files/modules, even when they look similar. It's the only thing standing between an accidental hashed_password leak and a clean API response.
Testing pyramid
  • Unit tests (fast, no I/O): core/security.py, pure service logic with fakes.
  • Integration tests (SQLite/Postgres + moto S3): most of what's shown above — one per endpoint/behavior.
  • A handful of true end-to-end tests against a docker-composed stack, run in CI on a schedule, not every PR.
Secrets discipline
.env is gitignored from commit #1. .env.example documents every variable with dummy values. Production secrets live only in GitHub Actions Secrets / AWS Secrets Manager, injected as environment variables at deploy time — never baked into the Docker image.
Pydantic validation everywhere
Every request body, query param, and response is a typed Pydantic model — including the "optional" endpoints. This gets you automatic 422s on bad input, OpenAPI schema generation, and IDE autocomplete for free; don't accept raw dict bodies.
JWT specifics
  • 1-hour expiry as required by spec — enforce via the exp claim, not application-side timers.
  • Sign with SECRET_KEY (HS256) for simplicity here; for multi-service deployments prefer RS256 with a private/public key pair so only the auth service can mint tokens.
  • Never put role/permission data in the JWT itself for this design — access is re-checked against ProjectAccess on every request, so a revoked invite takes effect immediately rather than waiting for token expiry.
Git/GitHub hygiene, summarized
  • Branch-per-phase, PR-per-phase, squash-merge, delete branch after merge.
  • Conventional commit prefixes: feat:, fix:, test:, ci:, chore:, refactor:, docs:.
  • Branch protection on main: required status checks + required review (even self-review discipline matters solo).
  • Tag releases (v0.1.0 after Phase 3, v1.0.0 after Phase 9) so you have restore points.
Normalization / denormalization (Phase-2 optional task, revisited)
The schema above is fully normalized (3NF): project_access is a proper join table, no duplicated data. Once GET /projects traffic grows, consider a denormalized read model — e.g. a materialized view or a project_summary table with document_count and total_size_bytes pre-computed by the Phase-7 Lambda — to avoid an aggregate query on every list call. Keep the normalized tables as the source of truth; denormalize only for read paths that need it.
DB creation with vs. without an ORM (Phase-2 optional task)
This roadmap uses SQLAlchemy + Alembic throughout. As a learning exercise, also write the equivalent schema.sql (raw CREATE TABLE statements + a thin psycopg2-based repository implementing the same BaseRepository interface) to see the same three-layer architecture hold up independent of the ORM choice — swap it in behind the same Service layer with zero router/service changes.
